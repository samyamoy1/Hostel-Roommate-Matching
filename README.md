K-Means Clustering on Student Data

This project uses K-Means Clustering from scikit-learn to group students based on sleep time and cleanliness.

Dataset
Two features: Sleep Time, Cleanliness
Manually created dataset converted into a NumPy array
What It Does
Applies K-Means with k = 2
Assigns cluster labels to each student
Computes cluster centroids
Visualizes clusters using Matplotlib
Output
Cluster labels (0 or 1)
Centroid coordinates
Scatter plot with clusters and marked centers
Run
pip install numpy matplotlib scikit-learn
python your_script_name.py
Purpose

To understand how unsupervised learning groups similar data without predefined labels.
